# TEDxSergeliSpecializedSchool

Official website for TEDxSergeliSpecializedSchool, built with React, TypeScript, Tailwind CSS and Vite.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Languages

The site supports Uzbek (default), Russian and English via a simple React context in `src/i18n`.
